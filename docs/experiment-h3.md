# H3 扩画、几何和提速实验

返回[历史实验档案](experiment-history.md)。同一段单人快速仰拍用于检查约 1.70 秒的头和双腕，四人舞蹈用于检查转场、地砖接续和最外围的黑带或异常蓝边。输出对照以贴回原片中心的双眼 VR180 视口为准。

## 扩画模型与投影

| 实验 | 方法与结果 | 处理决定 |
| --- | --- | --- |
| H3 Ref2VA 两种量化 | 紧凑 NVFP4 与 Q4_K 都产出对照，和 VACE、step9000 同帧比较。使用当时的视频参考流程容易偏离扩画原意，黑底和源画面边界都会被模型解释为画面内容。 | 后续改用 FL2VA 扩画流程。量化对照与工作流差异分开看。 |
| FL2VA T8 专用扩画 | 做四边扩展并用源片保护，同时测试无 H3 Union 的普通输出。灰底、原画彩色视频参考、纯黑参考与不同遮罩均做过对照。原始单目中存在观感自然的帧，将外围与双眼原片合成时，颈部、手腕和侧边仍会错位。 | 保留为 H3 基础路线，原片中心在模型外重新贴回。 |
| 无 Union 的接缝校正 | 复用 FL2VA 成片，接入外围亮度校正、二维过渡及原片颜色相关的后处理。可以减弱亮度突变，对生成轮廓的错位帮助有限。 | 保留共享后处理。 |
| 平面扩图后投影 | 比较保比例并让远端淡出、保持铺满并将拉伸推向远端。两种只改投影，双眼原片相同。人物轮廓仍与生成前的几何有关。 | 未设为默认。 |
| 先投影 110° 再用 FL2VA | 将原片放到球面网格，比较原彩色视频、黑底加遮罩及与 step9000 对应的全景参考坐标。直接全景化比旧平面版部分位置更接近，仍出现空间比例和接续差。 | 调整输入画布能改善部分位置，直接套用 step9000 的训练格式未解决 H3 错位。 |
| 标定与留出边缘 | 用已知原片边缘检验重投影，测试宽 32 像素的遮边生成，以及鱼眼 8 像素留出。合成形状、原片真值、VAE 直通、边缘复制、邻帧传播分别做对照。 | 保留几何验证方法。推理生成的轮廓误差仍需与投影误差分别检查。 |
| 上仰 38° 透视窗口 | 带原片重叠区做一次定向扩画，再按相机射线投回。对照全景版和 step9000。窗口在部分位置更易延续场景，快速运动时画外手仍会错接。 | 没有替代通用单画布。 |
| 150° 大平面与双视角 | 大画布生成后逐射线投回，未覆盖方向由已有全景补齐。人物比例较旧平面稳定，推理数据量较大。双视角重叠并同步去噪也生成了对照。 | 大平面保留画质参考。额外视图和重叠不适合作为日常快档。 |
| H3 全景 LoRA 和 VR180 双眼 LoRA | 做了普通全景、equi360 全景 LoRA、原生双眼 LoRA、原生前半球与 896×384 全景 A 版的实际输出及头显对照。通用提示下，单人快速仰拍的头和手仍接不好。专为镜头手写动作的方案不符合批处理要求。 | 未替代现用 H3 鱼眼路线。 |
| 等距鱼眼 A/B | 比较等距鱼眼本身和加首帧、侧边约束的 B 版。B 版近中轴头部较稳，腿和手靠两侧时仍会偏移。四人片也有固定采样密度三版，有一版后段掉画面。 | 采用 B 版思路配外围校正。 |
| 逐眼外围位移 | 同一份单目外围分别与单目、左眼和右眼比较，估计边界偏移，再逐眼修正。局部侧边能校正，快速出框人物的误差不能用统一位移量解释。 | 保留诊断和试验。双眼原片继续各自投影，外围仍可共用。 |

## 黑边、异常比例和画风

| 实验 | 方法与结果 | 处理决定 |
| --- | --- | --- |
| 448 画布、196° 保护边 | 单遍生成后仅取中央 180° 的射线，保留 110° 原片角域。半径约 201.6 像素，最外保护边约 17.9 像素。样片仍有黑带，异常可进入最终 180° 的可见范围。 | 宽黑带无法只靠这组裁边规格解决。 |
| 512 画布、206° 保护边 | 单遍生成，保留约 32 像素余量，再逆投影成 VR180。按同一段输出比较黑边和片尾蓝边。有的帧外缘改善，有的帧仍呈错误比例或异常色。 | 保留单遍和裁边设置。合成预览输出的像素宽高用于查看，保护边按生成坐标和角度核算。 |
| 放大、偏移和按帧取边界 | 用最差帧及全段实测检查固定轮廓、中心偏移、“只看第二秒”和逐帧异常。整图放大曾造成原片人物比例或位置错误。 | 停用全图放大修边。 |
| 轻量异常暗带修补 | 复用 3.67 秒现成扩画，仅检测并替换最外围异常带，后处理统计约 1.35 秒。可清掉部分角落，宽黑带和错误天空形状仍可能进入视口。 | 留作局部对照，无 Union 快档仍有风险。 |
| 镜头词、画幅词与材质词 | 同种子比较删去 fisheye 等镜头词，保留或删去通用方向词，追加 1:1、四边铺满、3D 动画材质、高质量、肢体与低纹理负面词。画风和黑带的位置会变化，宽黑框在多段仍出现。 | 基础提示保留通用画质与动画描述，未采用用提示词代替几何和引导的做法。 |
| 外围预填充与附加参考 | 试过弱背景参考、边缘反射/扩大、轮廓调整、按镜头背景关键帧、局部原尺度绘画、遮罩及视觉参考。可改变异常带，有的版本把天空或地砖带成错误结构。 | 未形成需默认开启的通用预填充。 |
| NVFP4 Compact、HQ、Pruned GGUF Q4_K_M | 同一问题镜头的采样用时约 176.8、175.9、467.4 秒。三组针对异常带的检测读数接近，换量化未消掉问题。另做了 HQ WebUI 实载。 | HQ 用于 H3 质量快捷键。GGUF 这组速度未过关，HQ 也不能单靠量化解决黑边。 |

黑带在模型生成帧中已经可见，合成和重投影会改变它在视口里的位置。裁边能避开模型画布边缘的一部分错误像素，覆盖更广的暗带、蓝带和错位轮廓需要在生成阶段约束。因此另外比较了 H3 Union 2.0。

## H3 Union 2.0 与完整计时

H3 Union 2.0 INT8 ConvRot 先测过生成后再重绘的方式，随后改为**主模型同一次采样内运行控制分支**。单遍仍需要计算控制分支，所以和完全关闭 Union 的运行成本不同。

| 四人舞蹈约 10 秒 | 扩画阶段 | 完整流程 | 记录 |
| --- | ---: | ---: | --- |
| 当时的 LTX step9000 对照 | 593.1 秒 | 750.9 秒 | 同段旧基准。 |
| H3 512 无 Union | 487.7 秒 | 638.0 秒 | 速度较快，宽边和背景结构风险更高。 |
| H3 加后二遍 Union 2.0 | 940.6 秒 | 1108.3 秒 | 有控制效果，第二遍成本高。 |
| H3 512 单遍 Union 2.0 | 551.2 秒 | 653.9 秒 | 单遍控制的质量路线。 |
| H3 640 单遍 Union 2.0 | 802.4 秒 | 900.9 秒 | 同段画布扩大，主采样约 622 秒，对比 512 的约 384 秒。 |

各组为各自记录的完整流程，模型路径、画布、采样和服务状态未跨架构统一。640 的额外像素不足以在这组对照中证明整体画质随耗时增加而稳定改善。H3 快档保留 512 无 Union，H3 质量捷径采用 HQ 权重和 H3 的单遍 Union。

## 采样、片尾和资源

| 实验 | 方法与结果 | 处理决定 |
| --- | --- | --- |
| CFG、步数和采样耗时 | 四人 10 秒同段，CFG 1.25/20 步、1.0/20 步、1.0/16 步完整耗时分别 1266.2、795.5、673.8 秒。日志显示 CFG 1.25 的 20 步每组控制调用 40 次，CFG 1.0 的 16 步为 16 次。室内暗场同两端配置约 560.4→349.8 秒。 | 提速可测，画外纹理和动作有变化，16 步保留为候选。 |
| 四条权重传输流 | 同一单人快速仰拍短片，CFG 1.0、16 步，两套完整流程记录约 366.0 和 349.3 秒。 | 单段次数不足以说明换流数有稳定收益。 |
| PDD 8 步 | 四人同段 CFG 1.0，PDD 8 步完整流程 713.1 秒，对照普通 16 步 673.8 秒。 | 这组整段耗时未降低。 |
| PNG 与内存映射中间帧 | 同一组 136 帧，PNG 读写约 8.1–8.4 秒，mmap 约 1.9 秒，复核了相同帧。 | 证明局部 I/O 有收益，完整流程的收益仍需分开计量。 |
| 近景短窗片尾 | 固定 CFG 1.25、20 步和种子，比较 Union 1.0、0.65，以及在同一镜头追加后续原片帧。短窗口约 152–156 秒，追加原帧约 338 秒，均复用立体缓存。 | 降 Union 未稳定消除背景崩坏。短窗上下文是这次主要线索，暂未对所有镜头增加前后帧。 |
| 人物保护与背景取色 | 同一个片尾窗口对比矩形保护、IS-Net 动漫人物轮廓及关闭保护。轮廓模型对 22 帧热机约 1.57 秒。画面比较中，切换保护本身没有可靠解决远处背景崩坏。 | 人物较大、20 步不足和取色污染的解释都没有单独得到验证。 |
| 关闭外围纹理简化、仅用触发词 | 对画外人物做同帧对照，检查双腕和脸部；简化强度及提示用词影响可见纹理，快速运动人物还是容易糊成连片。 | H3 保留在 WebUI，人物运动画质后续继续比较 LTX。 |
