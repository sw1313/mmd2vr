## 如何阅读结果

主要测试平台为 Windows RTX 5070 Ti 16 GB。标记为 NAS 的测试使用 RTX 4060 Ti 16 GB。**推理、扩画阶段与完整流程分别计时**。完整流程通常包括读取原片、深度及双眼合成、扩画、投影与接缝、编码和解码校验。复用缓存、复用立体片和仅处理单个推理窗口的记录单独说明。

画质主要在贴回原片中心的 VR180 成片上检查。取同一时间、同一视线方向的视口，对照原片比例和连续几帧，再检查画外新增人物、肢体接续、场景变化、接缝及闪烁。原片中心保护比较的是**相同投影和颜色格式下**的像素。编码前的零差异与有损成片的平均误差分开记录。历史上个别模型只留下中间片、单帧或任务日志，对应条目仅报告该范围内的结论。

## 早期立体合成与背景生成

| 实验 | 方法与结果 | 处理决定 |
| --- | --- | --- |
| 深度立体与头显成片 | 用 iw3 的 VDA Metric-L 生成双眼原片，再投影并封装为 5760×2880 左右眼 VR180。早期短片验证了完整解码、原片音轨、左右眼和球面标记。 | 采用。后续扩画均以双眼原片保护为前提。 |
| MMD 工程直接渲染 | 调研了按原人物、舞台、动作和相机工程直接渲染 VR180 的路线。视频样本缺少匹配工程，未做成片对照。 | 保留为有源工程时的路线。 |
| 镜头配准与真实舞台复用 | 固定舞台优先匹配已知背景，跨镜头配准后再用 FLUX 画远处。2.17 秒短片在正视高度附近约 13% 的框外区域有真实像素支撑。遮边回测可找回主要墙线，细砖缝仍有丢失。单张全景约 144 秒。 | 固定舞台有效，缺少可匹配机位的素材需走其他路线。 |
| 单张 FLUX 背景跟踪 | 四段不同镜头各生成一张背景，约 119–124 秒/张。高亮舞台在地平线附近的框外区域左右眼分别找回 9.6% 和 12.5% 的真实像素。两段室内素材缺少可靠匹配，近景出现与原布景断开的摆件。 | 保留固定背景实验结果。通用近景改用连续视频扩画。 |
| FLUX 文本与模型缓存 | 连续不同舞台使用相同 20 步。后两张平均 126.9→94.7 秒，三张均逐像素相同。另一组三张整体 6:55→5:20，舞台渲染 708 帧解码后最大差值为零。 | 当期采用。计时涵盖背景生成与渲染复验，NAS 整片收益没有由这组实验测得。 |
| 详细舞台与环境光分层 | 约 104 秒单人舞蹈的舞台数 19→6。样片复用生成缓存，将部分详细舞台替换为边缘取色的环境光，框外明显更软。少生成 13 张节省 30:53 是按旧任务累计时间估算的。 | 当期作为可选折中。 |
| 原片边缘颜色、纹理融合 | 同一双眼片和外围背景，仅更换融合。固定舞台样片在接缝两侧的平均颜色跳变从 29.6 降到 13.9。错误的外围墙线仍会露出。 | 保留原片边缘对齐与融合思路。 |
| ProPainter 修接缝 | 对上述 6 秒样片再加时序修补，跳变 13.9→13.2。离接缝约 3.5° 的区域反而出现更大的色差，两个镜头另用 76 秒。 | 未设为默认。 |
| MMD PLUS 图像模型 | 热机生成两块侧外围约 8 秒。直接生成容易将砖墙和室内改成绿墙。加入原片颜色、人物及低重绘强度后，近接缝更接近，远处仍拉成色带或出现重复纹理。 | 画质未过关。 |
| Anima-Base、LLLite Inpainting、Worldly | 两个镜头各生成一张 1024×1024 底图，固定种子、遮罩、30 步和 CFG 4。关闭/开启 Worldly 分别用 23.73/22.05 秒与 21.13/19.96 秒。两组都减少了早期 Wan 样片中的写实人头。Worldly 增加砖墙窗洞细节，床沿走向和窗格间距仍错。计时复用了估深与配准。 | 可作为静态背景候选。运动接缝和通用批处理未达到默认条件。 |
| SIFT 与 EfficientLoFTR 邻帧找宽视野 | 四支视频筛了 478 个候选。室内例有 33 帧通过匹配，遮住左右各 96 像素后，右侧能还原 53.5% 的遮住背景，左侧为 0%。两侧均没有可验证的原画外新增像素。已知 120 像素裁边的校验测得 119.96 和 119.85 像素。 | 采用留出验证思路。画内补回量需和画外新增量分开。 |
| ProPainterX 去人、固定布景与按段重建 | 对同一 2.2 秒近景，修改人物遮罩后比较共用布景和按段扩画。512 个背景点有 505 个近乎静止，分段反而产生换房间跳变。ProPainterX 底图准备约 77 秒，两段 VACE 共约 353 秒。 | 固定布景解决这处跳变，接缝和真实房间布局仍不可靠。 |
| 连续原帧替代独立背景参考 | 同一 2.2 秒近景，640×640 VACE 直接读含人物的整窗。可确认背景的右侧边缘平均差 23.9/255，分段方案为 42.0/255，固定布景为 64.2/255。左下依旧可能画出游离肢体，推理用时 338 秒。 | 成为早期近景流程的基准。曾在 NAS 用固定舞台、室内、竖屏及动态舞蹈等五支短片验证。 |
| 人物遮挡、邻帧查找与 E 版融合 | 从同镜头分别为左右眼找可见证据，原片像素一直保留到有效边界，融合在框外。两例在 44 像素外带中能由两帧印证的比例约为 4% 和 11%。床沿改善，鞋形仍有分叉。 | 采用原片保护原则。离开原画的轮廓仅在有可靠证据时复用。 |
| 少量背景参考帧、镜头跟踪复用 | 以 NAS 上 3 分钟片长、约 2 小时总耗时为目标，做过单人舞蹈和近景候选。固定背景对可跟踪布景有用，运镜与近景缺少足够的真实覆盖。 | 批量档目标尚缺同条件 3 分钟整片验收。 |

## Wan、修复模型与量化

### 同一段 10 秒舞蹈的模型输出对照

NAS RTX 4060 Ti 上使用同一段单人舞蹈、600 原帧。下表是模型对照记录中的耗时与整卡峰值。采样帧数、生成分辨率和调用方式随模型变化。图像模型各画三张关键图，不能用这组时间直接估算逐帧整片。此批早期对照主要用于看外围，后来另做了贴回原片的最终 VR180 样片。

| 模型 | 对照耗时 | 整卡峰值 | 结果 |
| --- | ---: | ---: | --- |
| Wan2.1 VACE 1.3B FP16 | 217.3 秒 | 10,732 MiB | 对照基线，连续性可用，外围偏软。 |
| Wan2.1 VACE 1.3B FP8 | 198.9 秒 | 8,426 MiB | 这一组中接近 FP16，显存更低，屋檐或人物外围易呈毛玻璃感。 |
| ProPainter 512 | 57.3 秒 | 6,783 MiB | 大面积未知区容易形成模糊色带。 |
| ProPainter ONNX FP16 | 72.6 秒 | 6,833 MiB | 量化/运行时变体中保留的 FP16 对照，仍有大面积模糊。 |
| ProPainter INT8 | 65.6 秒 | 7,713 MiB | 本次比原版耗时和整卡峰值都高，画质依然未过关。 |
| M3DDM+ 256 | 689.4 秒 | 14,175 MiB | 有输出，速度和外围观感均不占优。 |
| SD 1.5 | 34.6 秒 | 4,789 MiB | 关键图生成快，场景内容和边界经常对不上。 |
| SD 1.5 + 动漫 LoRA | 23.5 秒 | 4,789 MiB | 只改善部分风格，背景位置和连续性仍不可靠。 |

### Wan 产品路线及画质修正

| 实验 | 方法与结果 | 处理决定 |
| --- | --- | --- |
| 舞蹈与人物近景分流 | 早期舞蹈优先匹配空舞台，近景用保留人物的连续原帧。近景同段相对单张 FLUX 能延续床沿，远处仍偏软。 | 后续统一为连续扩画，原来的两个预设属于历史版本。 |
| 近景低帧率加光流 | 约 10 fps、16 步扩画，光流补回源帧率。同一 1.07 秒短片，标准档 155 秒、均衡档 73 秒。33.12 秒本机整片为 17:42，扩画与融合占 15:18。 | 提速成立。出框纹理较软，部分近景多出深折痕。 |
| 文本缓存、TeaCache 0.10 | 同一 33.12 秒近景整片，17:42→仅文本缓存 17:28→TeaCache 13:22。仅缓存文本的 993 帧压缩流哈希一致。补查左右两侧发现 Wan 均衡与 TeaCache 都有写实人头或越界肢体。 | 保留速度记录。撤回当时的画质通过结论。 |
| FP8 640、缓存与 16/32 步 | 固定 10 秒源片，比较 16 步开缓存、16 步关缓存、32 步关缓存。后两者扩画阶段 269.6 / 460.5 秒，完整流程 700.5 / 892.3 秒。32 步取样时暗区比例更大，外围梯度也未持续提高。 | 加步数未解决毛玻璃感。 |
| FP8 832、细节层和接缝 | 同一 10 秒片提高画布分辨率并加外围增强。完整流程 1002.9 秒，扩画 433.6 秒、边缘 242.2 秒、细节 92.2 秒。 | 分辨率提升成本明显，未形成通用默认。 |
| VACE 14B Q4_K_M | 10 秒 600 帧完整对照，含原片中心及投影，累计约 1761 秒。 | 留存候选与成片计时，未入默认流程。 |
| VACE-LTX 2B | 40 步，两个短窗热推理约 15.4 秒、13.7 秒，首次加载与文字初始化另约 104 秒。按镜头增加材质描述，仍接不准床沿和窗格。 | 停在短片门槛。 |
| 视觉描述与提示词 | 比较通用提示、按镜头手写描述、自动视觉描述、少生成独立人物和防暗角。个别窗格/材质更接近，其他镜头新增蓝弧、绿折线或仍有黑框。 | 个别镜头的改善未在多场景复现。 |
| 模型输入提亮与预填充 | 测过原片参考 γ=0.85、边缘颜色延续、主背景参考与先画平面再投影。提亮有时改善暗室，却在舞蹈场景留下黑框。按镜头取样仍受人物遮挡与几何支配。 | 未把统一提亮、逐片提示和人工选择设为默认。 |
| 生成参考人物保护 | 一组五种素材自动生成背景参考，并保护原片出框人物。多角色和近景均出现误伤或新增人体。 | 人数限制、背景去人和该批量引导方案都未采用。 |
| 用后来流程替换主模型为 Wan | 接上原片中心、参考掩码、深度和外围合成。约 5.03 秒近景，重放全景版约 569 秒，先平面扩画再投影版约 626 秒。Wan 另测原生双控制，而 LTX Union 的权重对应 LTX。 | 平面版改善不了普遍的错位和模糊，保留为实验。 |
| VACE Prep 与原生采样 | 单人舞蹈同一段，比较旧处理、灰底和 16 像素对齐的处理，以及按原生采样设置重跑。三版另与 step9000 对照。 | 流程差异可单独验证，未改变主选型。 |
| EditCtrl 1.3B | 49 帧，约 92 秒、整卡约 5.52 GiB。结果未通过外围画质检查。 | 停用。 |
| Wan2.2 VACE Fun A14B 量化 | 49 帧，约 514 秒、整卡约 10.80 GiB。 | 留存结果，未接入批处理默认。 |
| PanoWan | 49 帧，约 310 秒、整卡约 3.74 GiB。 | 有生成对照，未替代 step9000。 |

## 早期 NAS 整片实测

一段约 **104 秒、60 fps** 的单人舞蹈用 E 版、VDA Metric-L、立体强度 3.0、曲率 50%、FOV 100°，从读取原片到解码校验及落盘用 **1:28:58**。VACE 扩画 **40:51**、逐眼边缘融合 **29:27**，合计约占全程 79%。估深与双眼 **9:33**，切镜检测 **3:03**。邻帧匹配另用 **13:29**，和扩画并行。5760×2880 成片共 6240 帧，抽查 7 帧保护区的双眼平均亮度误差低于 0.63/255。这次验证了流程和瓶颈，历史半小时目标未达成。
